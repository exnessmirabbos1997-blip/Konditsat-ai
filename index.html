Mnemosxema

Nam materialni quritish qurilmasining texnologik va avtomatlashtirish sxemasi (chizma asosida). Qiymatlar real vaqtda yangilanadi: bunker sathi, shnek, gorelka alangasi, klapanlar holati va material oqimi.

Sxema: nam material konveyeri, bunker va aralashtirgich (M02), shnekli ta’minlagich (M01), tarozi (WT), o‘txona va gorelka, quritgich, siklon, yengli filtr, tayyor mahsulot bunkeri, so‘ruvchi ventilyator, mahsulot konveyeri, invertor, PLC, analog chiqish moduli va personal kompyuter. Yashil klapan — ochiq; qizil yoki sariq hoshiya — chegaradan chiqqan o‘lchov; “GORELKA TRIP” paneli himoya ishlaganda qizil yonadi.

3D ko‘rinish

Quritish qurilmasining uch o‘lchamli ko‘rinishi — mnemosxema bilan bir xil ma’lumotlardan olinadi (gorelka, quritish barabani, bunker, konveyerlar, siklon, filtr, mo‘ri, PLC va AI xavf indeksi). Sichqoncha bilan aylantiring, g‘ildirak bilan yaqinlashtiring, uskunani bosib ma’lumot ko‘ring. Pastdagi o‘ynatish tugmasi bilan jarayonni yurgizing.

AI xabarlari

    Indeks tarkibi

    Hodisa tahlili (Review)

    Tanlangan holat bo‘yicha avtomatik tahlil: sabab, voqealar ketma-ketligi, parametrlar o‘zgarishi, texnolog va KIP xulosasi.

    Hisoblanmoqda…

    Ommaviy sinov

    Har bir nosozlik turidan 10 tadan va 50 ta normal ish ssenariysi (joriy sozlamalar bilan).

    O‘z ma’lumotingiz

    PLC/SCADA trendini Excel (.xlsx) yoki CSV fayldan yuklang. Fayl brauzerdan tashqariga chiqmaydi.

    Majburiy ustunlar: TT01, TT02, FT01, FT02, FT03, LT01, WT, AT01, AT02. Ixtiyoriy: U11, U12 (klapanlar, %), M01, M02 (tezlik, %) — ular bo‘lmasa tegishli izchillik tekshiruvlari o‘chiriladi.

    Matematik model

    Vaqt — daqiqa, oqim — m³/soat (gaz, havo) va t/soat (material), harorat — °C, namlik — %.

    1. Gorelka va o‘txona

    Qg = u1-2·Qg,max, Qa1 = u1-1·Qa1,max, Qa2 = u1-3·Qa2,max λ = Qa1 / (9,5·Qg) Tf* = T0 + η·Qg·Hu·min(1, λ) / ((Qg + Qa1)·cp), τf·dTf/dt = Tf* − Tf

    2. Quritish agenti (aralashma)

    Td* = ((Qg + Qa1)·Tf + Qa2·T0) / (Qg + Qa1 + Qa2), τd·dTd/dt = Td* − Td

    3. Quritish va mahsulot namligi

    E = κ·Qda·ca·(Td − Tchiq) / r (bug‘latish qobiliyati, t/soat) W = F·wkir/100, w* = wkir·exp(−β·E / W), τp·dw/dt = w* − w, AT02(t) = w(t − tk)

    4. Bunker va ta’minot

    dL/dt = 100·(Fkir − F) / (60·Mb), F = uM01·Fmax·kf (normal ishda kf = 1; shnek tiqilganda yoki M02 to‘xtaganda kf < 1)

    5. Boshqaruv va himoya (PLC)

    u1-2: PI, TT02 → topshiriq; u1-1: FT02 → λ0·9,5·FT01; u1-3 = const TT01 ≥ 1180 °C, TT02 ≥ 400 °C yoki λ ≤ 0,95 ⇒ gorelka o‘chiriladi LT01 ≤ 5 % ⇒ M01 to‘xtaydi; LT01 ≥ 95 % ⇒ konveyer 1 to‘xtaydi; AT02 ≥ 8 % ⇒ sifat hodisasi

    6. AI: izchillik qoldiqlari

    rT = (TT02 − Td*(TT01, FT01, FT02, FT03)) / 12 rG = (FT01 − u1-2·Qg,max) / (0,03·Qg,max), rA = (FT02 − u1-1·Qa1,max) / (0,03·Qa1,max) rF = (WT − uM01·Fmax) / (0,03·Fmax), rM = (M02 − uM02) / 1,5 rI = (WT̄ + Mb·dL/dt − Fkir,nom) / 1, rW = (AT01 − wnom) / 1

    7. Dinamik xavf indeksi

    x₁ = chegaraga yaqinlik (alarm → 0,5, himoya → 1) x₂ = clip(1 − τ/Tu), τ — hodisagacha vaqt (AT02 uchun model bashorati bo‘yicha) x₃ = max(Isolation Forest bali, clip((max|r| − 3)/2)) x₄ = clip((max|r| − 3)/4) R = maxj(w₁x₁ⱼ + w₂x₂ⱼ) + w₃x₃ + w₄x₄, R ≥ R* ketma-ket 3 o‘lchov ⇒ ogohlantirish

    Isolation Forest: 100 daraxt, 256 tanlanma, 30 ta normal ssenariyda qoldiqlar vektori [rT, rG, rA, rF, rM, rI, rW] bo‘yicha o‘qitiladi. Sabab tashxisi |r| ≥ 4 qoidalari asosida (ustuvorlik: TT02, gaz, havo, M02, shnek, kelim, namlik).

    8. Taxminiy parametrlar

    Qg,max = 400, Qa1,max = 4500, Qa2,max = 12000 m³/soat; Hu = 34 000 kJ/m³ (34 MJ/m³); cp = 1,45 kJ/(m³·K) (issiq gaz); ca = 1,35 kJ/(m³·K) (quritish agenti); r = 2800 kJ/kg (bug‘lanish issiqligi); κ = 0,92; β = 1,88; T0 = 20 °C; Tchiq = 120 °C; Fmax = 10,5 t/soat; stexiometrik havo 9,5 m³/m³; τf = 4, τd = 1,5, τp = 6 daq, kechikish tk = 3 daq; η = 0,5; Fkir = 7 t/soat; wkir = 18 %; Mb = 30 t; TT02 topshiriq 350 °C. Barcha qiymatlar taxminiy — real qurilma ma’lumotlari bilan almashtirilishi kerak.
